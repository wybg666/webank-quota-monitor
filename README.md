# 微众银行产品额度监控 · Python 独立版（非官方）

一个使用 Python 3.11 标准库实现的本地网页工具：查看公开产品货架，手动选择目标产品，在明确开启监控及通知权限后接收额度事件提醒。

**本项目不是微众银行官方软件，不需要银行账号，不提供登录、账户查询、买入或卖出功能。** 这是一次全新的 Python 功能重写，不是 EXE 破解，没有实现原程序的 License 激活算法，也不声称与 Go 版本 100% 等价。目前不操作微信。

## 先了解数据边界

- 只请求原有公开接口 `personalv6.webankwealth.com/wm-htrserver/finance/product_shelf/query_pls_sub_list_no_auth`。
- 查询范围固定为 `MTFUND_PLUS_SUB_DETAIL` 单一货架的第 1 页，`page_size=100`，**不是银行全部产品**，不会自动翻页。
- 显示的是源接口原始额度数值，**不是个人可购买额度**。尚未独立核实所有字段的金额单位、更新延迟及业务含义，不保证实际可购；请以银行官方页面为准。
- 销售状态保留接口原值，提醒条件使用原实现的状态 `"12"`，并不等于交易一定能成功。
- 缺失额度显示为未知，不伪造为 `0`。接口失败时保留上次结果并标识异常，旧结果不代表最新状态。
- 这是当前可读取的公开未登录接口，不是稳定性承诺；银行可能改变字段、访问条件或停用接口。程序不会尝试登录或绕过认证。
- 工具不提供投资建议，也不承诺收益、额度或通知送达。

## 快速开始

需要 **Python 3.11 或更新版本**。全部使用标准库，**无需 `pip install`**；`requirements.txt` 仅用于说明没有第三方 Python 依赖。

### Windows

1. 将完整项目保存在本机，保留 `webank_monitor` 及其 `static` 子目录。
2. 双击 `start.bat`。也可以在项目根目录的终端执行：

   ```powershell
   python -B run.py --open-browser
   ```

3. 浏览器打开本机页面 `http://127.0.0.1:8790/`。启动程序**不会自动查询或启动轮询**。
4. 点击“查询一次”查看当前货架。这个操作只读一次，**不发送通知**。
5. 按需选择目标产品、保存设置，再手动启动监控。结束时先停止监控，关闭终端或按 `Ctrl+C` 退出程序。

`start.bat` 优先使用 Windows Python Launcher；如机器同时安装多个 Python，请确认被选中的版本不低于 3.11。

端口占用时可另选端口，不会结束占用端口的其他程序：

```powershell
python -B run.py --port 8791 --open-browser
```

### 只查询一次，输出 JSON

```powershell
python -B run.py --probe
```

只发起一次公开只读请求，不启动网页、轮询或通知。成功时输出产品、带时区的抓取时间、来源、范围与警告；失败时输出简短错误并返回非零退出码。请勿把它放入高频重试脚本。

### 离线演示

```powershell
python -B run.py --demo --open-browser
```

演示使用明确标注的独立示例数据，不请求银行业务接口。**演示模式永久禁止全部通知**，即使同时传入 `--allow-notifications` 也不发送。演示配置与事件使用独立的 `-Demo` 数据目录，不应把演示结果当作真实额度。

## 监控与提醒规则

| 设置 | 默认值与行为 |
| --- | --- |
| 查询间隔 | 15 秒，最低允许 5 秒；上次查询结束后再等待下一轮，不并发查询 |
| 连续失败上限 | 3 次；失败后延长等待，达到上限停止，需检查后手动重新启动 |
| 暂停时段 | UTC+8 的 `00:00–07:00`；暂停时不请求接口，支持如 `23:00–07:00` 的跨午夜区间 |
| 目标产品 | 默认空；按产品**完整名称精确匹配**，不是关键词匹配 |
| 新产品提醒 | 默认关闭；“新品”仅指相对本工具基准新增，不代表银行正式新品 |
| 要求额度大于 0 | 默认开启；额度未知或为 0 时不提醒 |
| 额度变化提醒 | 默认开启；符合条件的目标发生额度变化时可形成新提醒 |
| 同产品提醒冷却 | 默认 60 秒；避免短时间重复通知 |
| 通知渠道 | 语音、邮件、Bark 默认全部关闭 |

默认间隔下，连续第 1、2 次失败后的等待约为 30、60 秒，第 3 次失败即停止。查询成功会清除连续失败计数。网络请求与暂停会影响实际查询时刻，因此不是精确到秒的调度保证。

默认暂停时段内启动监控，会保持暂停，而不是立刻查询。需要检查数据时，可先停止监控，再点击“查询一次”。起止时间同时留空或设为相同时间表示不设置暂停窗口。

没有已保存的新品基准时，**首次成功查询的当前页只用于建立内存基准，不会把该页所有产品误报为新品**。页面可将当前列表保存为判断基准；未保存的内存基准会在退出后丢失，下一次启动重新建立。保存后的基准随本机设置保留。目标产品提醒仍按所选完整名称和额度条件独立判断。

手动查询不发送提醒，也不会消耗自动监控的状态变化与冷却记录。停止监控时，已经发起的请求可能仍需等待结束或超时。

## 通知：需要两层明确开启

通知必须同时满足：

1. 进程以 `--allow-notifications` 启动；
2. 页面中启用具体渠道并保存有效配置。

```powershell
python -B run.py --open-browser --allow-notifications
```

仅保存配置、仅勾选渠道、仅启动普通 `start.bat`，都不会授权发送。`--probe` 和“查询一次”也不会发送。页面上的通知测试是主动投递操作，需先完成上述两步；测试消息不是产品事件。

- **语音**：只支持 Windows，通过系统 PowerShell 和 SAPI 语音组件播放；取决于本机语音组件及设备是否可用。
- **邮件**：使用用户配置的 SMTP 服务器，支持 SSL 或 STARTTLS，开启 TLS 证书校验；不支持明文 SMTP。填写发送者、收件人和服务器要求的凭据。
- **Bark**：使用配置的设备密钥向 `api.day.app` 投递；本版本不提供自定义 Bark 服务地址。
- **微信**：未实现，也不会控制本机微信。

邮件与 Bark 会把提醒内容交给配置的邮件服务或 Bark 服务。请确认接收方、密钥及服务使用条件后再开启。事件中的“已跳过”表示没有投递，不能当成送达成功。

**本次验证没有真实播放语音、发送邮件或推送 Bark，不能据此声称各渠道已完成正式送达测试。** 用户应在明确授权后自行测试使用中的渠道。

## 本机数据与隐私

默认 Windows 数据目录：

```text
%LOCALAPPDATA%\WebankQuotaMonitorPython
%LOCALAPPDATA%\WebankQuotaMonitorPython-Demo
```

其中 `settings.json` 保存本机配置，`events.json` 保存近期事件。可通过环境变量 `WEBANK_MONITOR_DATA_DIR` 指定真实模式的数据目录；演示模式在该目录名后加 `-Demo`，避免混用。非 Windows 环境默认使用 `XDG_DATA_HOME`，未设置时使用用户目录下的 `.local/share`。

配置文件中，**邮箱密码和 Bark 设备密钥以明文保存在本机磁盘**。设置读取接口只将这两个秘密字段展示为 `********`，这只是防止页面回显，**不是加密存储**。用户名、发送者和收件人等配置也属于隐私。请保护数据目录及备份，避免共享、同步或上传它们。

程序不保存银行账号、登录 Cookie 或银行凭据。查询使用每实例随机生成的设备参数，不借用个人账户会话。

## 本机网页安全边界

- 默认只监听 `127.0.0.1:8790`，不监听公网或局域网地址。
- 检查请求 Host；更改设置、查询及启停等操作需要本机页面令牌，并检查请求来源以降低 CSRF 风险。
- 这些措施不构成多用户登录或访问控制系统。本机其他程序仍可能访问本机服务。
- **不要通过反向代理、端口转发、隧道或修改监听地址将它公开。** 本工具没有公网部署或远程账户管理功能。
- 银行接口请求保持 HTTPS 证书验证，不自动跟随重定向；压缩响应和解压内容分别限制为 2 MiB，异常结构、重复产品 ID 和非有限额度会拒绝本次快照。
